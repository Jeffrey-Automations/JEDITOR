## U-20261115-01 · 2026-11-15 · Window shell and built-in themes (roadmap M1, layout part) · #done #ui #theme

- **Decision**: the layout direction `PROGRESS.md` #9 was waiting on is the activity bar / side bar / editor / bottom panel / secondary side bar arrangement, with the project's own themes as the default and the qt-material styles kept selectable.
- **What**: `EditorMain` now builds a `Workbench` (`pyside_ui/main_ui/shell/`) around the editor tabs. The file tree and the output views (run result, format check, debugger output, terminal, variables, Git client) are one set per window rather than one per tab; an `EditorWidget` in a window with a shell points its existing attributes (`project_treeview`, `code_result`, `git_gui`, `code_difference_result`, …) at them and builds its own only in a host window without a shell, so stand-in windows and embedders are unaffected. Side bar: Explorer, Outline, Run and Debug, Testing, TODO. Bottom panel: Output, Problems, Terminal, Source Control, Debug Console, Format Check, Variables. Secondary side bar: AI chat. Views other than the explorer and the output ones are built on first show. A file clicked in the Explorer opens in its own tab (a blank tab is reused); tabs are titled with the file name. Layout state is pure data (`utils/shell/layout_state.py`) stored as `shell_layout`.
- **Themes**: `jeditor_dark` (new default) and `jeditor_light`, one QSS template filled from tokens (`utils/theme/ui_theme.py`, `ui_stylesheet.py`); line icons as SVG text (`ui_icons.py`) recoloured on a theme change; editor colours get a palette per built-in theme. Every style is applied through `apply_ui_style()`. `start_editor()` no longer applies `dark_amber.xml` over the configured style. A project whose settings already name a qt-material style keeps it. The editor font default is now a monospaced list.
- **Also**: a View menu; shortcuts `toggle_side_bar` (Ctrl+Shift+B), `toggle_bottom_panel` (Ctrl+`), `toggle_secondary_side_bar` (Ctrl+Alt+I), `show_explorer` (Ctrl+Shift+E); the current branch in the status bar; running a program, the pdb console, the format check and the debug adapter each reveal their view. 18 new strings in all four dictionaries.
- **Files**: `je_editor/pyside_ui/main_ui/shell/*`, `je_editor/utils/shell/*`, `je_editor/utils/theme/ui_*.py`, `je_editor/pyside_ui/main_ui/menu/view_menu/build_view_menu.py`, `main_editor.py`, `editor/editor_widget.py`, `toolbar/toolbar_builder.py`, `menu/style_menu/build_style_menu.py`, `start_editor.py`; READMEs, `docs/source/docs/{Eng,Zh}/{configuration,keyboard_shortcuts,getting_started}.rst`, `architecture.md`, `architecture_explore.md`; `image/screenshot-main-window.png` and `screenshot-light-theme.png` retaken.
- **Evidence**: `test/test_workbench.py`, `test/test_shell_layout.py`, `test/test_ui_theme.py`; the two launch scripts under `test/qt_ui/unit_test/` run offscreen.
